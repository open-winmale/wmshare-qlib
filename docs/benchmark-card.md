## ② alpha 基准（预算边界，未做）

以 `D.instruments("csi300")` × 3y 跑一次 Alpha158-lite + LGBM 的成本结构
（按实测确定性计价，docs/optimization-roadmap.md §2.5）：

- 一次性建仓：300 票 × ~12.3k EC（n=750 hfq 双拉 + 估值 4 + 资金流）
  ≈ **3.7M EC**；
- 日频维护：~13.6k（日 bar）+ 周/月估值资金流摊销 ≈ **~50k/天**；
- 结论：**预算允许前不做**；届时命令就是 README 现有的
  `dump-history --live`（csi300 codes 文件）→ `update-history` →
  `alpha158_lgbm.py` 三步，无需新代码。
